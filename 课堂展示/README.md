# 课堂展示材料

本文件夹包含 10 页 PPT、逐页讲稿、数字备忘和可交互的现场网页。建议讲解时间约 **9 分钟**。

## 使用顺序

1. 放映 `北京二手房单价预测_课堂汇报.pptx`。
2. 按 `逐页讲稿.md` 讲解。第 9 页切换到网页 Demo。
3. 在**项目根目录**执行以下命令，程序会自动打开本机浏览器：

```powershell
uv sync
uv run python 课堂展示/现场演示.py
```

在本项目中运行时，网页后端直接导入 `src/common.py` 的特征配置和决策树管线。若只拷贝这个展示文件夹到其他电脑，在该文件夹执行 `python -m pip install -r requirements-demo.txt`，然后执行 `python 现场演示.py`（Python 3.11 及以上）；此时使用同配置的 `demo_model.py` 快照。Demo 所需的清洗数据、模型结果和网页文件均已放在文件夹内。若浏览器没有自动打开，复制终端显示的 `http://127.0.0.1:端口/` 地址。按 Ctrl+C 结束。Demo 只监听本机，运行时不需要联网；启动时按与正式实验相同的划分和设置拟合决策树。

网页由 `web_demo/index.html`、`app.css` 和 `app.js` 组成，通过本机 `/api/meta` 与 `/api/predict` 调用 Python 模型，不能直接双击 HTML 文件使用。页面包含六项可调整的房源输入、预测与真实值的柱形对比、三条测试样例，以及从 `data/model_scores.csv` 读取的三模型成绩对比。建议现场按“朝阳两居 → 西城两居 → 房山两居 → 修改房山区县并重新预测”的顺序演示。三条样例都来自固定测试集。修改房源条件后，页面会停止用原房成交价评价新条件。

`分析备忘.md` 列出数据规模、缺失情况、完整模型指标、价格分段误差和结论边界，供答辩时查阅。

`制作PPT.js` 和 `assets/` 是 PPT 的生成源文件；已经生成的 `.pptx` 可直接放映，不需要运行它。若要重新生成 PPT，先安装 Node.js 与 `pptxgenjs`，再在本文件夹执行 `node 制作PPT.js`。
